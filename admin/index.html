WEBSITE MANAGEMENT

网站后台已经分成两部分

Squidex 管理网站设置和商品资料；GitHub 只存放商品图片。客户访问 jinhuan.me 时看到的是正常独立站，不会看到 Squidex 或 GitHub 后台。

打开 Squidex 后台打开商品图片目录查看网站前台
① 网站设置在 Squidex 建立 site-settings，管理首页标题、Banner、About、Contact、颜色和联系方式。
② 商品管理在 Squidex 的 products 中管理商品名称、SKU、尺寸、材质、颜色、描述和图片路径。
③ 商品图片上传到 GitHub 的 assets/products/商品SKU/ 文件夹，例如 JH-001/01.jpg。
④ 前台展示Squidex 商品发布后，jinhuan.me 自动读取资料；图片通过 jinhuan.me 自己的地址加载。
